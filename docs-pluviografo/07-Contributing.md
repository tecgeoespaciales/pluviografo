# Contributing

Guía rápida
- Abre un issue para proponer cambios o reportar bugs.
- Crea una rama por feature: `feature/mi-cambio`.
- Haz pull request hacia `profesional` o `main` según workflow.

Commit messages
- Mensajes breves y descriptivos. Ej: `Fix: handle reed switch debounce`.

Código y pruebas
- Verifica que los cambios en firmware no introduzcan secretos.
- Añade documentación o actualiza `docs-pluviografo/` cuando cambies comportamiento.
