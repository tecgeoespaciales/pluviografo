# Mechanical — Pluviógrafo

Contenido
- Modelos CAD y piezas imprimibles en `mechanical-pluviografo/`.

Consejos de montaje
- Montar el reed switch en un soporte estable para evitar vibraciones.
- Proteger la electrónica con caja estanca y respiraderos para equilibrar presión interna.
- Añadir espuma o amortiguador para el pluviómetro si se expone a alta vibración.
